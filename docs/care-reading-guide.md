# CARE close-reading guide · 精读指南

阅读对象是 Garcia 等人的 **Clinical AI Readiness Evaluator（临床人工智能就绪度评估框架，CARE）** 总论。下面同时给出期刊页码和本地 PDF 页码。目标是把文章读成一组可以回答的工程问题，再用自己的工作台展示可以验证的部分。[CARE 论文](https://academic.oup.com/ajcp/article/164/3/424/8197944)

## 第一遍，先抓论文的主张（约 20 分钟）

1. **期刊 424–425 页，本地第 1–2 页**。读摘要、引言和实施障碍。用一句话写下研究到实施的差距（research-to-implementation gap）：实验数据上能跑的模型，需要证据证明它适合具体用户、数据来源和工作环境，才能进入临床流程。
2. **期刊 429–430 页，本地第 6–7 页，图 3 和图 4**。横向读从早期研究到部署的**技术就绪度等级（Technology Readiness Level，TRL）**，纵向读八条工作流。图 3 的回退（switchback）表示发现缺口时返回补证据。图 4 的阶段审查（gated review）表示证据齐备才进入下一阶段。挑一个工作流读到另一端，例如数据管道从数据可用性走向实际环境中的处理与校验。
3. **期刊 435 页，本地第 12 页，图 7**。三个案例分别关注部署环境不匹配、合作开发前的数据可用性判断、供应商平台与机构系统的兼容性。重点读第一行：质谱峰分类模型研究时用 R，目标管道用 Python，迁移需要超过 250 小时。对应到 demo，及早冻结输入契约并在实际容器环境验证模型加载和服务启动。[图 4 的框架说明](https://academic.oup.com/view-large/figure/531416871/aqaf069_fig4.jpg) · [论文正文和图 7](https://academic.oup.com/ajcp/article/164/3/424/8197944)

## 第二遍，把八条工作流映射到你能展示的证据（约 25 分钟）

| CARE 工作流 | 这个 demo 可以拿出的证据 | 若往真实实验室推进，还要追问 |
| --- | --- | --- |
| 临床用例（Clinical use case） | 展示复核一个合成面板的决定和审计记录 | 谁使用、何时使用、结果会触发什么实际动作？ |
| 数据（Data） | 合成生成器版本、随机种子、字段单位、标签来源和固定数据划分 | 参考标签怎样确认？是否代表未来人群和数据来源？ |
| 数据管道（Data pipeline） | 输入契约、单位定义、缺失处理、重复请求识别，推理直接使用训练产物 | 实际仪器、来源和数据传输变化如何检测？ |
| 代码（Code） | 可复现模型训练、自动化测试、容器构建和启动检查 | 谁负责维护、代码审核和版本发布？ |
| 临床用户体验（Clinical user experience） | 浏览器可查看原始输入、预测和审核历史 | 审核是否减少工作量，哪些信息会影响审核者的判断？ |
| 临床技术基础设施（Clinical technology infrastructure） | Streamlit 与 FastAPI 分层，两个服务健康检查，版本化模型文件 | 将来要接什么系统，有哪些身份、网络和运行环境约束？ |
| 临床编排（Clinical orchestration） | 现场走通校验、模型推理、人工复核、监控及回滚 | 真实告警交给谁？什么情况下要暂停、修复或回滚？ |
| 监管合规（Regulatory compliance） | 说明演示用途、使用合成数据、保留操作记录 | 真正拟定用途和风险等级后，需由哪些机构负责人评估？ |

这张对照表是你的面试准备工具。论文把阶段就绪度建立在多条工作流的证据上。本项目的证明范围是本地合成演示。数据溯源（data lineage）续篇可进一步对照数据组成、来源、标注和使用限制。[CARE 总论](https://academic.oup.com/ajcp/article/164/3/424/8197944) · [数据溯源续篇](https://academic.oup.com/ajcp/article-abstract/165/5/aqag029/8675909)

## 最后，准备三个追问（约 10 分钟）

- **部署（Deployment）**。“CARE 图 7 提醒我尽早验证目标环境。我把拟合好的预处理和模型一起交给预测服务，容器启动后做健康检查。每条预测会带上模型版本和文件校验值。”
- **机器学习运维（Machine Learning Operations，MLOps）**。“我先区分输入变化和表现变化。偏移告警支持调查输入管道。候选模型验证需要可靠的参考标签。模型切换有记录，也可以回滚。”
- **和 Eric 的研究怎么连？** Day、Eric Lantz 等人的公开摘要显示，同一批模型在不同标签来源下会得到不同评价。演示用合成病例复现这个风险。早期光谱审核研究有开放全文，可读它如何将模型提示和人工判断纳入质量审核。2026 年反馈循环论文的队列划分与标签判定细节仍待全文核对。[反馈循环论文摘要](https://doi.org/10.1093/clinchem/hvag001) · [早期光谱审核全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11975758/)
